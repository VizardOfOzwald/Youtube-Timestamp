YOUTUBE TIMESTAMP TOOLS - HOW TO INSTALL (2 minutes, no coding)
================================================================

1. EXTRACT this zip file
   Right-click the downloaded file -> "Extract All" (or "Unzip").
   You should now have a folder called "youtube-timestamp-tools".

2. OPEN CHROME'S EXTENSIONS PAGE
   Open Chrome, type this in the address bar and press Enter:
   chrome://extensions
   (Edge: edge://extensions   |   Brave: brave://extensions)

3. TURN ON "DEVELOPER MODE"
   Flip the "Developer mode" toggle in the TOP-RIGHT corner.

4. CLICK "LOAD UNPACKED"
   A folder picker opens. Select the "youtube-timestamp-tools"
   folder you extracted in step 1 (the one that contains the
   file "manifest.json").

5. DONE! The extension is installed.
   - Open any YouTube video or Short - a small dark panel appears.
   - Press "+ Add loop" or "+ Add skip" and use the "Now" buttons
     to grab the current time.
   - Click the puzzle-piece icon in Chrome's toolbar and PIN
     "YouTube Timestamp Tools" to always see it.

TIP: To hide the panel, press the X on it. To bring it back,
press the small round red button on the video.

Your loops and skips are saved automatically for every video.
Nothing is uploaded anywhere - everything stays in your browser.
